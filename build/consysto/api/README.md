# Канал управления Consysto Files

Другая программа на этом компьютере может вести окно Consysto Files: открывать папки,
делить окно на панели, заводить коллекции и планы резервных копий, начинать закачки.

По умолчанию всё выключено. Включается в «Настройки → Дополнительно → Управление из
других программ».

## Два входа

**Именованный канал** `\\.\pipe\ConsystoFiles` — основной. Права на него имеет только
та учётная запись, под которой запущена программа; из сети до него не дотянуться.

**Вход по http** на `http://127.0.0.1:<порт>` (по умолчанию 3577) — необязательный,
для тех, кому канал неудобен: веб-страница, скрипт на любом языке. Порт открыт всем
программам этого компьютера, поэтому нужен ключ: он лежит в файле `api-key.txt` в данных
программы и передаётся заголовком `X-Consysto-Key`. Кнопка «Показать файл ключа» в тех же
настройках открывает папку с ним.

## Как устроен разговор

Запрос — одна строка JSON, ответ — одна строка JSON. По каналу можно послать несколько
запросов подряд, не разрывая соединение.

```json
{"command":"open","path":"D:\\Проекты\\Гриль","where":"other"}
```

Ответ всегда содержит `ok`. При отказе есть `error` с причиной, при успехе у большинства
команд есть `window` — что сейчас в окне: вкладки, их названия и пути, папки открытых
панелей и какая панель активна.

## Команды

| Команда | Что делает | Поля |
|---|---|---|
| `ping` | проверка, что окно отвечает | — |
| `state` | что сейчас в окне | — |
| `open` | открыть папку или страницу | `path`; `where`: `tab` (по умолчанию), `current`, `other` |
| `splitPanes` | развернуть окно на две панели | `path` — необязательно, что показать во второй |
| `closePane` | убрать вторую панель | — |
| `focusPane` | передать управление панели | `index`: 0 или 1 |
| `selectTab` | перейти на вкладку | `index` |
| `closeTab` | закрыть вкладку | `index` — по умолчанию текущая |
| `run` | выполнить любую команду программы по имени | `name` |
| `createCollection` | завести коллекцию | `name`, `folders`, `where` — вид коллекции |
| `createBackup` | завести план резервной копии | `name`, `path` — что копировать, `folders` — куда |
| `addTorrent` | начать закачку | `path` — файл `.torrent` или magnet-ссылка, `name` — папка |

Страницы форка адресуются как папки: `Terminal:<папка>`, `Torrents:`,
`Collection:<название>`, `Sync:<номер>`.

Команда `run` — это вход в общий список команд программы, тот же, что в палитре:
`{"command":"run","name":"ToggleShowHiddenItems"}`.

## Примеры

PowerShell, через готовый скрипт [Send-FilesCommand.ps1](Send-FilesCommand.ps1):

```powershell
.\Send-FilesCommand.ps1 open -Path 'D:\Проекты\Гриль'
.\Send-FilesCommand.ps1 splitPanes -Path 'D:\Проекты\Плита'
.\Send-FilesCommand.ps1 state
```

По http, любым языком:

```powershell
$key = Get-Content "$env:LOCALAPPDATA\ConsystoFiles\api-key.txt"
Invoke-RestMethod -Uri http://127.0.0.1:3577/ -Method Post `
    -Headers @{ 'X-Consysto-Key' = $key } `
    -Body ([Text.Encoding]::UTF8.GetBytes('{"command":"ping"}'))
```

В портативной версии файл ключа лежит в `data\Local\api-key.txt` рядом с программой.
